# Tastenkürzel {#tastenkuerzel}

Alle Tastenkürzel von Manta auf einen Blick, nach Themen geordnet. Die Befehlspalette (**⇧⌘P**) zeigt neben jedem Befehl sein Kürzel – auch die der Plugins. Auch die Menüleiste listet alle Befehle mit ihren Kürzeln (**Ablage**, **Bearbeiten**, **Darstellung**, **Gehe zu**, **Fenster**), wie im Finder – so finden auch Apps, die die Kürzel der aktiven App anzeigen, alle Kürzel von Manta. Ein Klick auf einen Menübefehl führt ihn aus.

Zeichen: **⌘** Befehl · **⇧** Umschalt · **⌥** Wahl · **⌃** Control · **↩** Zeilenschalter · **⌫** Rückschritt · **⌦** Entfernen · **⇥** Tabulator

## Allgemein {#allgemein}

| Kürzel | Befehl |
|---|---|
| ⇧⌘P oder ⌘P | Befehlspalette |
| ⌘, | Einstellungen … |
| ⌘? | Handbuch öffnen (dieses Handbuch; im Hilfefenster: Suchfeld) |
| ⌘K | Mit Server verbinden … |
| ⌥⌘L | Übertragungen einblenden |
| ⇧⌘S | Vergleichen und synchronisieren … |
| ⌘H | Manta ausblenden |
| ⌥⌘H | Andere ausblenden |
| ⌘Q | Manta beenden |

## Bereiche und Tabs {#bereiche}

| Kürzel | Befehl |
|---|---|
| ⇥ / ⇧⇥ | Bereich wechseln (zum nächsten / vorherigen, ringsum) |
| ⌥⌘← / ⌥⌘→ | Bereich links / rechts aktivieren |
| ⌘D | Bereich teilen |
| ⇧⌘D | Bereich schließen |
| ⌘T | Neuer Tab |
| ⌘W | Tab schließen (in Einstellungen, Vergleichen und Vorschau: Fenster schließen) |

## Ansichten {#ansichten}

| Kürzel | Befehl |
|---|---|
| ⌘1 | Als Symbole |
| ⌘2 | Als Liste |
| ⌘3 | Als Spalten |
| ⌘4 | Als Galerie |
| ⌘ + Scrollen oder Zusammenziehen/Aufziehen | Symbolgröße ändern (Symbolansicht) |
| ← / → | Spaltenansicht: zur Spalte links / ausgewählten Ordner als nächste Spalte öffnen |
| ← / → | Symbol- und Galerieansicht: vorheriges / nächstes Objekt |

Die Kürzel wirken auf den aktiven Bereich. Siehe [Ansichten](03-ansichten.md).

## Auswahl {#auswahl}

| Kürzel | Wirkung |
|---|---|
| ↑ / ↓ | Vorheriges / nächstes Objekt |
| ⇧↑ / ⇧↓ | Auswahl erweitern |
| Bild ↑ / Bild ↓ | 20 Zeilen nach oben / unten |
| Pos1 / Ende | Erstes / letztes Objekt |
| ⌘A | Alles auswählen |
| esc | Auswahl aufheben (oder Vorschau schließen) |
| Buchstaben tippen | Zum passenden Namen springen |

| Kürzel | Befehl |
|---|---|
| Leertaste oder ⌘Y | Schnellansicht / Vorschau (Leertaste oder esc schließt) |
| ⌘I | Informationen |
| F5 | In anderen Bereich kopieren … |
| F6 | In anderen Bereich bewegen … |
| F2 | Umbenennen … (bei mehreren Objekten: stapelweise) |
| ⇧⌘R | Stapelweise umbenennen … |
| ⇧⌘N | Neuer Ordner … |
| ⌥⌘N | Neue Datei … |
| ⌘⌫ oder ⌦ | In den Papierkorb legen (auf Servern: nach Rückfrage endgültig löschen, siehe [Löschen](05-dateien.md#loeschen)) |
| ⌥⌘⌫ | Sofort löschen … (endgültig, nach Rückfrage) |
| ⇧⌘⌫ | Papierkorb entleeren … (nach Rückfrage, siehe [Papierkorb](07-favoriten-seitenleiste.md#papierkorb)) |
| ⌥⌘C | Komprimieren … |
| ⌥⌘E | Hier entpacken |
| ⌘ beim Ziehen | Bewegen statt Kopieren vorwählen (ohne Taste ist Kopieren vorausgewählt; ⌥ wählt ausdrücklich Kopieren) |

> [!NOTE]
> Auf vielen Mac-Tastaturen musst du für **F2**, **F5** und **F6** zusätzlich die Taste **fn** (🌐) drücken – außer du hast in den Systemeinstellungen unter **Tastatur** „F1, F2 usw. als Standard-Funktionstasten verwenden“ eingeschaltet.

## In Dialogen und Fenstern {#dialoge}

| Kürzel | Wirkung |
|---|---|
| ↩ | Bestätigen (z. B. Kopieren, Erstellen, Umbenennen) |
| esc | Dialog abbrechen |
| ⌘W | Einstellungen, Vergleichen und synchronisieren oder Vorschau schließen |

**Befehlspalette**: ↑ ↓ zum Auswählen · ↩ zum Ausführen · esc zum Schließen

**Gehe zum Pfad**: ↩ öffnet in neuem Tab · ⌘↩ öffnet in diesem Tab · ⇥ ergänzt · esc bricht ab

## Wann Kürzel nicht wirken {#fokus}

- In einem **Textfeld** (Filter, Pfad, Dialogfelder) funktionieren nur **⇧⌘P**, **⇧⌘G**, **⌘,** und **⌘?**; alle anderen Tasten gehören dem Textfeld.
- Im **Terminal** gehören **⌘C**, **⌘V**, **⌘A**, **⌘K**, **⌘←**, **⌘→** und **⌘⌫** dem Terminal. Klicke in die Dateiliste, um Manta die Tastatur zurückzugeben.
- In den Fenstern **Einstellungen**, **Vergleichen und synchronisieren** und **Vorschau** wirken nur deren eigene Kürzel.

## Bedienung ohne Maus {#tastatur}

Manta lässt sich vollständig mit der Tastatur bedienen.

| Taste | Wirkung |
|---|---|
| ⌃F5 | Tastaturfokus in die Steuerelemente: beginnt in der Symbolleiste (wie in macOS „Fokus auf Symbolleiste“) |
| ⇥ / ⇧⇥ | In den Steuerelementen: weiter / zurück – Symbolleiste → Seitenleiste → Bereiche (Pfadleiste, Spaltenköpfe, Dateiliste) → Statusleiste, dann wieder von vorn |
| ↑ ↓ ← → | In Seitenleiste, Dialogen und Optionslisten: zum nächsten Steuerelement in dieser Richtung |
| Leertaste / ↩ | Fokussierte Taste, Option oder Schalter auslösen |
| esc | Steuerelemente verlassen – die Dateiliste hat wieder die Tastatur; in Dialogen: abbrechen |
| ⇥ / ⇧⇥ in der Dateiliste | Zum nächsten / vorherigen Bereich |

- Die **Dateiliste** ist ein einziger Tabulator-Halt pro Bereich (nicht jede Zeile). Hat sie den Fokus, gelten alle Dateilisten-Kürzel: Pfeile, ↩, Leertaste, Buchstaben zum Springen.
- Ein **Fokusring** in der Akzentfarbe zeigt, welches Steuerelement die Tastatur hat. Mausklicks setzen keinen Fokusring.
- **Dialoge** halten den Fokus: ⇥ wandert nur durch ihre Felder und Tasten. Nach dem Schließen (auch von Einstellungen) kehrt der Fokus dorthin zurück, wo er vorher war.
- Mit **Tastaturnavigation** in den Systemeinstellungen (Tastatur) funktionieren die Kürzel genauso; ⌃F5 ist dort ebenfalls „Fokus auf Symbolleiste“.

## Unterschiede zum Finder {#finder}

| Kürzel | Finder | Manta |
|---|---|---|
| ⌘D | Duplizieren | Bereich teilen |
| ⇧⌘D | Schreibtisch öffnen | Bereich schließen |
| ⇧⌘P | Vorschau einblenden | Befehlspalette |
| ⌘R | Original zeigen | Aktualisieren |
| ⌥⌘C | Pfadnamen kopieren | Komprimieren … |
| ⌥⌘L | Downloads öffnen | Übertragungen einblenden |
| ⌫ | – | Übergeordneter Ordner |

Wie im Finder: **⌘⌫** legt in den Papierkorb, **⌥⌘⌫** löscht sofort, **⇧⌘⌫** entleert den Papierkorb, **⌘T** öffnet einen neuen Tab, **⌘Y** die Schnellansicht, außerdem **⇧⌘N**, **⇧⌘G**, **⇧⌘.**, **⌘[** / **⌘]**, **⌘↑** / **⌘↓**, **⌘1** – **⌘4**, **⌘K** und **⌃⌘T** (zur Seitenleiste/zu den Favoriten hinzufügen). Beim Ziehen ist Kopieren vorausgewählt, auch auf demselben Volume (der Finder bewegt dort); **⌘** wählt Bewegen.

> [!NOTE]
> **Neu in dieser Version:** **⌘T** öffnet einen neuen Tab (bisher **⇧⌘T**), die Übertragungen liegen auf **⌥⌘L** (bisher **⌘T**), **⌘⌫** legt lokale Objekte in den Papierkorb (bisher endgültiges Löschen; das ist jetzt **⌥⌘⌫**). Manta weist nach dem Update einmal darauf hin.
