# Git {#git}

Если папка находится в репозитории Git, Manta показывает статус каждого файла прямо в списке, ветку — в строке пути, а также панель Git для индексирования и создания коммитов. На вашем Mac должен быть установлен `git` (например, вместе с Xcode Command Line Tools).

![Список файлов со значками Git и панелью Git](images/git-panel.png)

## Статус в списке файлов {#abzeichen}

У измененных файлов есть значок. Наведите на него указатель, и подсказка объяснит статус:

- **Изменен, не проиндексирован** / **Проиндексирован для коммита** / **Изменен, частично проиндексирован**
- **Добавлен, проиндексирован для коммита**
- **Не отслеживается** (новый файл, Git его еще не знает)
- **Удален, не проиндексирован** / **Удаление проиндексировано для коммита**
- **Переименован из …** / **Скопирован из …**
- **Конфликт слияния**
- **Игнорируется в .gitignore** — такие файлы приглушены.

Папки показывают, сколько измененных файлов в них содержится («Внутри 3 измененных файла»).

## Ветка в строке пути {#chip}

Метка в строке пути показывает текущую ветку. Ее подсказка сообщает больше:

- какую вышестоящую ветку она отслеживает и опережаете вы ее или отстаете («Отслеживает origin/main (впереди на 2)»),
- последний коммит,
- «Отсоединенный HEAD на …», если ни одна ветка не выбрана.

Если выполняется слияние, перебазирование, cherry-pick, отмена коммита или bisect, метка это показывает. Нажатие на метку открывает панель Git.

## Панель Git {#seitenleiste}

Показать или скрыть ее: **⇧⌘B** (**Показать/скрыть панель Git**) или нажмите метку ветки.

Панель показывает:

- вверху ветку, вышестоящую ветку и число коммитов для отправки или получения,
- группы **Конфликты**, **Проиндексированные**, **Изменения** и **Неотслеживаемые**,
- поле **Сообщение коммита**,
- **Недавние коммиты**.

### Создание коммита {#commit}

1. Откройте панель Git клавишами **⇧⌘B**.
2. Проиндексируйте файлы: **Индексировать** у файла или **Индексировать все** у группы **Изменения**.
3. Нажмите файл, чтобы увидеть его изменения (diff).
4. Введите **Сообщение коммита**.
5. Нажмите **Коммит** или нажмите **⌘↩**.

Manta сообщит «Создан коммит abc1234: …».

Чтобы отменить индексирование: **Убрать из индекса** или **Убрать все из индекса**.

### Разрешение конфликтов {#konflikte}

При конфликте слияния затронутые файлы перечислены в группе **Конфликты**. Разрешите конфликт в своем редакторе, затем выберите **Отметить как разрешенный (индексировать)**. Когда все конфликты разрешены, панель сообщает «Создайте коммит, чтобы завершить слияние». Для перебазирования, cherry-pick и отмены коммита она показывает соответствующую команду `--continue` для Терминала.

## Обновление {#aktualisieren}

Manta обновляет статус Git автоматически. При необходимости: **Обновить статус Git** в палитре команд или кнопка обновления в панели.

## Ограничения {#grenzen}

- Git работает только для **локальных** папок («Статус Git доступен для папок на этом Mac, но не на серверах.»).
- Отправка (push), получение (pull), переключение веток и слияние выполняются в [Терминале](11-terminal.md) или в программе для Git. Панель показывает статус, индексирует и создает коммиты.
