# Быстрый просмотр и просмотр {#schnellansicht}

Нажмите **Пробел**, чтобы посмотреть файл, не открывая его. Для файлов на вашем Mac Manta использует **Быстрый просмотр** Apple, как Finder; для файлов на серверах и в архивах есть **встроенный просмотр**.

## Быстрый просмотр файлов {#leertaste}

1. Выберите файл.
2. Нажмите **Пробел** (или **⌘Y**, как в Finder).
3. Клавишами **↑** и **↓** переходите к предыдущему или следующему файлу — панель следует за выбором.
4. **Пробел** или **esc** закрывает просмотр.

Если выбрано несколько файлов, стрелки **‹** и **›** в Быстром просмотре листают выбранные объекты.

Клавиатура остается в Manta: пока панель Быстрого просмотра открыта, вы можете перемещаться по списку клавишами со стрелками.

## Быстрый просмотр (macOS) {#quick-look}

Быстрый просмотр — панель просмотра Apple. Она показывает все, что показывает Finder: PDF, изображения, видео, документы Office, текстовые файлы и многое другое. Она работает для **локальных** файлов и папок.

## Встроенный просмотр {#integrierte-vorschau}

Файлы на **серверах** (SFTP, FTP, S3, контейнеры) и **в архивах** открываются в собственном окне просмотра Manta, потому что Быстрый просмотр Apple знает только локальные файлы.

- Встроенный просмотр показывает **текстовые файлы** и **изображения**.
- Для больших текстовых файлов показывается начало («Показаны первые … файла.»).
- Для других типов файлов (например, PDF или видео) он сообщает, что это за файл, и предлагает открыть его клавишей ↩. Тогда Manta загрузит его и откроет в программе по умолчанию.
- Папки он не показывает — нажмите ↩, чтобы открыть папку. (Быстрый просмотр Apple показывает локальные папки.)
- Закрыть: **Пробел** или **⌘W** (это отдельное окно с обычными кнопками окна).

![Встроенный просмотр текстового файла с сервера](images/preview-builtin.png)

## Что открывает Пробел {#einstellung}

В разделе **Настройки** → **Основные** → **Просмотр** → **Пробел открывает** выберите:

- **Быстрый просмотр (macOS)** — по умолчанию.
- **Встроенный просмотр** — и для локальных файлов.

Для файлов на серверах и в архивах всегда используется встроенный просмотр.

## Дополнительный просмотр от плагинов {#plugins}

- **Просмотр Markdown** (**⌥⌘M**): показывает файлы `.md` красиво оформленными на боковой панели — см. [Просмотр Markdown](14-plugins.md#markdown).
- **Инструменты изображений**: показывают размер изображения, цветовой профиль и данные EXIF — см. [Инструменты изображений](14-plugins.md#bildwerkzeuge).

## Ограничения {#grenzen}

- Быстрый просмотр работает только с локальными файлами. Manta (пока) не загружает файлы с сервера, чтобы показать их в Быстром просмотре.
- Встроенный просмотр показывает только текст и изображения.
