# Сочетания клавиш {#tastenkuerzel}

Все сочетания клавиш Manta с первого взгляда, сгруппированные по темам. Палитра команд (**⇧⌘P**) показывает сочетание клавиш рядом с каждой командой — и для команд плагинов тоже. Строка меню также перечисляет все команды с сочетаниями клавиш (**Файл**, **Правка**, **Вид**, **Переход**, **Окно**), как в Finder, — поэтому программы, показывающие сочетания клавиш активной программы, находят все сочетания Manta. Выбор команды в меню выполняет ее.

Символы: **⌘** Command · **⇧** Shift · **⌥** Option · **⌃** Control · **↩** Return · **⌫** Delete (удаление назад) · **⌦** Forward Delete (удаление вперед) · **⇥** Tab

## Общие {#allgemein}

| Сочетание | Команда |
|---|---|
| ⇧⌘P или ⌘P | Палитра команд |
| ⌘, | Настройки… |
| ⌘? | Открыть руководство (это руководство; в окне справки — поле поиска) |
| ⌘K | Подключение к серверу… |
| ⌥⌘L | Показать передачи |
| ⇧⌘S | Сравнить и синхронизировать… |
| ⌘H | Скрыть Manta |
| ⌥⌘H | Скрыть остальные |
| ⌘Q | Завершить Manta |

## Панели и вкладки {#bereiche}

| Сочетание | Команда |
|---|---|
| ⇥ | Сменить панель (на следующую, по кругу) |
| ⌥⌘← / ⌥⌘→ | Перейти к панели слева / справа |
| ⌘D | Разделить панель |
| ⇧⌘D | Закрыть панель |
| ⌘T | Новая вкладка |
| ⌘W | Закрыть вкладку (в Настройках, окне «Сравнение и синхронизация» и в просмотре — закрыть это окно) |

## Виды {#ansichten}

| Сочетание | Команда |
|---|---|
| ⌘1 | Как значки |
| ⌘2 | Как список |
| ⌘3 | В колонках |
| ⌘4 | Как галерея |
| ⌘ + прокрутка или сведение пальцев | Изменить размер значков (вид «Значки») |
| ← / → | Вид «Колонки»: перейти в колонку слева / открыть выбранную папку следующей колонкой |
| ← / → | Виды «Значки» и «Галерея»: предыдущий / следующий объект |

Сочетания клавиш действуют на активную панель. См. [Виды](03-ansichten.md).

## Выбор {#auswahl}

| Сочетание | Действие |
|---|---|
| ↑ / ↓ | Предыдущий / следующий объект |
| ⇧↑ / ⇧↓ | Расширить выбор |
| Page Up / Page Down | На 20 строк вверх / вниз |
| Home / End | Первый / последний объект |
| ⌘A | Выбрать все |
| esc | Снять выбор (или закрыть просмотр) |
| Ввод букв | Перейти к подходящему имени |

| Сочетание | Команда |

| F6 | Переместить в другую панель… |

| ⇧⌘N | Новая папка… |
| ⌘⌫ или ⌦ | Переместить в Корзину (на серверах: удалить навсегда после вопроса, см. [Удаление](05-dateien.md#loeschen)) |
| ⌥⌘⌫ | Удалить немедленно… (навсегда, после вопроса) |

> На многих клавиатурах Mac для **F2**, **F5** и **F6** нужно удерживать **fn** (🌐) — если только вы не включили «Использовать клавиши F1, F2 и др. как стандартные функциональные клавиши» в разделе «Системные настройки» → **Клавиатура**.

## В окнах и диалогах {#dialoge}

| Сочетание | Действие |
|---|---|
| ↩ | Подтвердить (Копировать, Создать, Переименовать …) |
| esc | Отменить диалог |
| ⌘W | Закрыть Настройки, окно «Сравнение и синхронизация» или просмотр |

**Палитра команд**: ↑ ↓ — выбрать · ↩ — выполнить · esc — закрыть

**Переход по пути**: ↩ открывает в новой вкладке · ⌘↩ открывает в этой вкладке · ⇥ дополняет · esc отменяет

## Если сочетания клавиш не работают {#fokus}

- В **текстовом поле** (фильтр, путь, поля диалогов) работают только **⇧⌘P**, **⇧⌘G**, **⌘,** и **⌘?**; все остальные клавиши относятся к полю.
- В **Терминале** **⌘C**, **⌘V**, **⌘A**, **⌘K**, **⌘←**, **⌘→** и **⌘⌫** относятся к Терминалу. Нажмите в списке файлов, чтобы вернуть клавиатуру Manta.
- В окнах **Настройки**, **Сравнение и синхронизация** и **просмотра** работают только их собственные сочетания клавиш.

## Отличия от Finder {#finder}

| Сочетание | Finder | Manta |
|---|---|---|
| ⌘D | Дублировать | Разделить панель |
| ⇧⌘D | Открыть Рабочий стол | Закрыть панель |
| ⇧⌘P | Показать просмотр | Палитра команд |
| ⌘R | Показать оригинал | Обновить |
| ⌥⌘C | Скопировать путь | Сжать… |
| ⌥⌘L | Открыть Загрузки | Показать передачи |
| ⌫ | – | Папка уровнем выше |

Как в Finder: **⌘⌫** перемещает в Корзину, **⌥⌘⌫** удаляет немедленно, **⇧⌘⌫** очищает Корзину, **⌘T** открывает новую вкладку, **⌘Y** открывает Быстрый просмотр, **⇧⌘N**, **⇧⌘G**, **⇧⌘.**, **⌘[** / **⌘]**, **⌘↑** / **⌘↓**, **⌘1** – **⌘4**, **⌘K** и **⌃⌘T** (добавить в боковое меню/Избранное). Перетаскивание заранее выбирает «Копировать», даже на том же томе (Finder там перемещает); **⌘** выбирает «Переместить».

> [!NOTE]
> **Изменено в этой версии:** **⌘T** открывает новую вкладку (раньше: **⇧⌘T**), передачи переехали на **⌥⌘L** (раньше: **⌘T**), **⌘⌫** перемещает локальные объекты в Корзину (раньше: удаление навсегда; теперь это **⌥⌘⌫**). Manta сообщает об этом один раз после обновления.
