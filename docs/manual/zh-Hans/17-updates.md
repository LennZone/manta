# 更新 {#updates}

Manta 每次启动时都会静默检查是否有新版本，并且只在你同意后才安装。本章介绍更新的工作方式、哪些数据会通过网络传输，以及更新失败时该怎么办。

## 如何得知有更新 {#hinweis}

有新版本时，你会看到：

- 一条“有可用的更新：0.2.0”通知，带有 **显示** 按钮；
- 状态栏中的一个小提示（“更新 0.2.0”）。

不会有任何窗口弹出打断你的工作。如果 Manta 处于离线状态，你不会察觉到任何异常；失败信息只会写入日志。

## 手动检查更新 {#suchen}

- 菜单栏中的 **Manta** → **检查更新…**，或者
- 命令面板中的 **检查更新…**，或者
- **设置** → **通用** → **更新** → **立即检查**。

如果一切都是最新的，Manta 会提示“Manta 已是最新版本”。

## 安装更新 {#installieren}

1. 点按通知中的 **显示**（或状态栏中的提示）。**软件更新** 窗口随即打开。
2. 阅读 **新功能**。上方显示大小和发布日期。
3. 选择：
   - **安装并重新启动**：下载更新、进行验证、替换 App 并重新启动 Manta。
   - **稍后**：下次启动时再次提醒你。
   - **跳过此版本**：不再提供此版本及更早的版本。

![“软件更新”窗口](images/software-update.png)

下载期间你可以看到进度，也可以取消。如果仍有传输正在进行，Manta 会等它们完成后再重新启动。如果 Manta 无法写入“应用程序”文件夹，macOS 可能会要求你输入密码。

如果出现问题，窗口会显示原因，并提供 **重试** 按钮。你当前的版本保持不变。

## Manta 无法自行更新时 {#blockiert}

| 信息 | 解决方法 |
|---|---|
| “Manta 正从磁盘映像运行” | 将 Manta 拖到“应用程序”文件夹，然后从那里打开。 |
| “Manta 正从临时位置运行” | macOS 从只读副本启动了 Manta（App 转移）。请使用访达将 Manta 移到“应用程序”文件夹，然后从那里打开。 |
| “此版本未设置更新” | 你的版本无法验证更新。请从网站下载新版本。 |

## 通道：稳定版和 Beta {#kanaele}

在 **设置** → **通用** → **更新** → **通道** 中选择：

- **稳定版**（默认）：仅限正式发布的版本。
- **Beta**：也包括预发布版本。它们能更早带来新功能，但可能包含错误。

Manta 绝不会提供比已安装版本更旧的版本。

## 安全性 {#sicherheit}

每个更新都经过数字签名。Manta 只会安装使用 Manta 团队密钥签名、且与所公布版本完全一致的更新。被篡改的下载内容会被拒绝（“更新的签名不正确，因此未安装任何内容。”）。更新仅通过 HTTPS 传输。

## 隐私：检查更新时会发送什么 {#datenschutz}

检查时，Manta 会从更新服务器（`manta-filemanager.com`）下载两个小文件：版本列表及其签名。通过网络传输的内容包括：

- 你的 **IP 地址**（与任何网页请求一样）；
- 标识 **`Manta-Updater/<version>`**，也就是你所使用的 Manta 版本。

Manta **不会** 发送用户 ID、设备标识、文件名或使用数据。哪个版本适合你（通道、macOS 版本、已跳过的版本）由你 Mac 上的 Manta 决定，而不是由服务器决定。

如果你不希望这样，请关闭 **启动时检查更新**。这样 Manta 只会在你自己选择 **检查更新…** 时才联网检查更新。

与几乎所有网站一样，Web 服务器会记录这些请求及其 IP 地址。托管服务提供商会按照其自身的保留规则处理这些记录；Manta 本身不会分析这些请求，也不会将其与任何内容关联。
