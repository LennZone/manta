# 键盘快捷键 {#tastenkuerzel}

Manta 的所有键盘快捷键一览，按主题分组。命令面板（**⇧⌘P**）会在每个命令旁边显示其快捷键，插件命令也不例外。菜单栏同样会列出每个命令及其快捷键（**文件**、**编辑**、**显示**、**前往**、**窗口**），与访达相同，因此能显示当前 App 快捷键的工具可以找到 Manta 的全部快捷键。点按菜单命令即可执行它。

符号：**⌘** Command · **⇧** Shift · **⌥** Option · **⌃** Control · **↩** Return · **⌫** Delete（退格）· **⌦** 向前删除 · **⇥** Tab

## 通用 {#allgemein}

| 快捷键 | 命令 |
|---|---|
| ⇧⌘P 或 ⌘P | 命令面板 |
| ⌘, | 设置… |
| ⌘? | 打开手册（即本手册；在帮助窗口中：搜索栏） |
| ⌘K | 连接服务器… |
| ⌥⌘L | 显示传输 |
| ⇧⌘S | 比较与同步… |
| ⌘H | 隐藏 Manta |
| ⌥⌘H | 隐藏其他 |
| ⌘Q | 退出 Manta |

| ⌥⌘← / ⌥⌘→ | 聚焦左侧面板 / 聚焦右侧面板 |
| ⌘D | 拆分面板 |
| ⇧⌘D | 关闭面板 |
| ⌘T | 新建标签页 |
| ⌘W | 关闭标签页（在设置、比较与同步和预览中：关闭该窗口） |

## 视图 {#ansichten}

| 快捷键 | 命令 |
|---|---|
| ⌘1 | 为图标 |
| ⌘2 | 为列表 |
| ⌘3 | 为分栏 |
| ⌘4 | 为画廊 |

## 文件 {#dateien}

| 快捷键 | 命令 |
|---|---|

| F5 | 拷贝到另一个面板… |
| F6 | 移到另一个面板… |
| F2 | 重新命名…（多个项目时：批量重新命名） |
| ⇧⌘R | 批量重新命名… |
| ⇧⌘N | 新建文件夹… |
| ⌘⌫ 或 ⌦ | 移到废纸篓（在服务器上：询问后永久删除，请参阅[删除](05-dateien.md#loeschen)） |
| ⌥⌘⌫ | 立即删除…（询问后永久删除） |
| ⇧⌘⌫ | 清倒废纸篓…（询问后执行，请参阅[废纸篓](07-favoriten-seitenleiste.md#papierkorb)） |

> 在许多 Mac 键盘上，使用 **F2**、**F5** 和 **F6** 时需要按住 **fn**（🌐），除非你已在“系统设置”→ **键盘** 中打开“将 F1、F2 等键用作标准功能键”。

## 在对话框和窗口中 {#dialoge}

| 快捷键 | 作用 |
|---|---|
| ↩ | 确认（拷贝、创建、重新命名等） |
| esc | 取消对话框 |
| ⌘W | 关闭设置、比较与同步或预览 |

**命令面板**：↑ ↓ 选择 · ↩ 执行 · esc 关闭

**前往路径**：↩ 在新标签页中打开 · ⌘↩ 在当前标签页中打开 · ⇥ 补全 · esc 取消

## 快捷键不起作用时 {#fokus}

- 在 **文本栏**（过滤、路径、对话框中的输入栏）中，只有 **⇧⌘P**、**⇧⌘G**、**⌘,** 和 **⌘?** 有效；其他所有按键都归该输入栏使用。
- 在 **终端** 中，**⌘C**、**⌘V**、**⌘A**、**⌘K**、**⌘←**、**⌘→** 和 **⌘⌫** 归终端使用。点按文件列表即可将键盘交还给 Manta。
- 在 **设置**、**比较与同步** 和 **预览** 窗口中，只有它们自己的快捷键有效。

## 仅用键盘操作 {#tastatur}

Manta 可以完全用键盘操作。

| 按键 | 作用 |
|---|---|
| ⌃F5 | 把键盘焦点移到控件，从工具栏开始（与 macOS 的“将焦点移到窗口工具栏”相同） |
| ⇥ / ⇧⇥ | 在控件中：下一个 / 上一个——工具栏 → 边栏 → 面板（路径栏、列标题、文件列表）→ 状态栏，然后循环 |
| ↑ ↓ ← → | 在边栏、对话框和选项列表中：移到该方向的下一个控件 |
| 空格键 / ↩ | 按下有焦点的按钮、选项或开关 |
| esc | 离开控件——键盘回到文件列表；在对话框中：取消 |
| 文件列表中的 ⇥ / ⇧⇥ | 切换到下一个 / 上一个面板 |

- 每个面板的**文件列表**只占一个 Tab 停留点（不是每一行）。它获得焦点时，所有文件列表快捷键照常使用：方向键、↩、空格键、输入字母跳转。
- 强调色的**焦点环**显示哪个控件拥有键盘。鼠标点按不会显示焦点环。
- **对话框**会保持焦点：⇥ 只在其字段和按钮之间移动。对话框（包括设置）关闭后，焦点回到原来的位置。
- 在系统设置（键盘）中打开**键盘导航**后，一切照常；⌃F5 在那里同样是“将焦点移到窗口工具栏”。

## 与访达的区别 {#finder}

| 快捷键 | 访达 | Manta |
|---|---|---|
| ⌘D | 复制 | 拆分面板 |
| ⇧⌘D | 打开桌面 | 关闭面板 |
| ⇧⌘P | 显示预览 | 命令面板 |
| ⌘R | 显示原身 | 刷新 |
| ⌥⌘C | 拷贝路径名称 | 压缩… |
| ⌥⌘L | 打开“下载” | 显示传输 |
| ⌫ | – | 上层文件夹 |

与访达相同的有：**⌘⌫** 移到废纸篓，**⌥⌘⌫** 立即删除，**⇧⌘⌫** 清倒废纸篓，**⌘T** 打开新标签页，**⌘Y** 打开快速查看，以及 **⇧⌘N**、**⇧⌘G**、**⇧⌘.**、**⌘[** / **⌘]**、**⌘↑** / **⌘↓**、**⌘1** – **⌘4**、**⌘K** 和 **⌃⌘T**（添加到边栏/个人收藏）。拖移时预选“拷贝”，即使在同一宗卷上也是如此（访达在这种情况下会移动）；按住 **⌘** 则预选“移动”。

> [!NOTE]
> **此版本中的更改：** **⌘T** 打开新标签页（以前：**⇧⌘T**），“传输”改为 **⌥⌘L**（以前：**⌘T**），**⌘⌫** 将本地项目移到废纸篓（以前：永久删除；现在改为 **⌥⌘⌫**）。更新后 Manta 会显示一次这些更改。
