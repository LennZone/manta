## Manta 0.4.2 – new files, container controls, rename by click

- **New File (⌥⌘N):** in the File menu and in the context menu of a pane – creates an empty file (“untitled.txt” suggested, the name without the extension selected) and selects it
- **Start, restart and stop containers:** right-click a Docker container in the sidebar – a stopped one offers Start, a running one Restart and Stop; the row shows the progress, a message confirms the result
- **Click to rename:** click an already selected item once more – in the List view its name becomes editable right in the row (↩ renames, Esc cancels), in the other views the Rename dialog opens
