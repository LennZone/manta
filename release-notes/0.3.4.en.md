## Manta is now open source

- **Free software under the MIT licence** – the source is on GitHub: github.com/web-workers-com/manta. Contributions welcome
- **Install plugins easily:** from a file (.zip/.mantaplugin) or a folder, with an overview of author, version, source and declared permissions before anything runs
- **For plugin developers:** templates in Python, Node.js, Rust and shell, a test harness, a developer mode (`--plugin-dev`) and "Reload Plugins"
- **Help › Source Code on GitHub…** and "Discover Plugins" in Settings
