## Manta 0.4.3 – app icons, folder sizes that stick, create inside folders

- **App icons like Finder:** apps (`.app`) show their own icon in every view, the List view included
- **Applications in the sidebar:** right below Home
- **Folder sizes are remembered:** after a restart they show at once and are re-measured quietly in the background – a changed size updates by itself
- **Create inside a folder:** right-click a folder – **New Folder in “…”** and **New File in “…”** create right in it; ⇧⌘N and ⌥⌘N keep creating in the folder shown, like Finder
- **Start a stopped container:** when a container stops while it is open, the pane offers **Start Container** instead of Try Again and lists the folder again once it runs
