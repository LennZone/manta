## Manta 0.4.4 – file icons from macOS, live folder sizes

- **File icons from macOS:** files show the icon macOS has for their type, apps their own – in every view, on servers too, like Finder. Settings → General → Files → **File icons from macOS** switches back to Manta's symbols
- **Folder sizes update live:** when something changes inside a sub-folder – also by another app – Manta re-measures it shortly afterwards; the old size stays shown meanwhile
- **Folder size cache in ~/Library/Caches:** no longer in Application Support, so Time Machine doesn't back it up
- **Quick Actions:** Cancel now reliably stops every process of an action (before, a script could still run one more command)
- **Website:** links in the plugin developer docs lead to the files on GitHub
