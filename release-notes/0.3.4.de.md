## Manta ist jetzt Open Source

- **Freie Software unter der MIT-Lizenz** – der Quellcode liegt auf GitHub: github.com/web-workers-com/manta. Mitmachen ist willkommen
- **Plugins einfach installieren:** aus einer Datei (.zip/.mantaplugin) oder einem Ordner, mit Übersicht über Autor, Version, Quelle und angegebene Berechtigungen, bevor etwas läuft
- **Für Plugin-Entwickler:** Vorlagen in Python, Node.js, Rust und Shell, ein Testwerkzeug, ein Entwicklermodus (`--plugin-dev`) und „Plugins neu laden“
- **Hilfe › Quellcode auf GitHub …** und „Plugins entdecken“ in den Einstellungen
