## Manta 0.4.4 – Dateisymbole von macOS, Ordnergrößen live

- **Dateisymbole von macOS:** Dateien zeigen das Symbol, das macOS für ihren Typ hat, Apps ihr eigenes – in allen Ansichten, auch auf Servern, wie im Finder. Einstellungen → Allgemein → Dateien → **Dateisymbole von macOS** schaltet zurück auf Mantas Symbole
- **Ordnergrößen aktualisieren sich live:** Ändert sich etwas in einem Unterordner – auch durch andere Apps –, misst Manta ihn kurz darauf neu; bis dahin bleibt die alte Größe sichtbar
- **Größen-Cache in ~/Library/Caches:** nicht mehr unter Application Support, damit Time Machine ihn nicht sichert
- **Quick Actions:** Abbrechen beendet jetzt zuverlässig alle Prozesse einer Aktion (vorher konnte ein Skript noch einen Befehl ausführen)
- **Website:** Links in der Plugin-Entwicklerdoku führen zu den Dateien auf GitHub
