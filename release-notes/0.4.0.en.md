## Manta 0.4 – faster, more accessible, better connected

- **Accessibility:** VoiceOver reads files, buttons and messages; full keyboard control with a visible focus; Reduce Motion, Increase Contrast and Reduce Transparency are honoured
- **Huge folders stay smooth:** folders with hundreds of thousands of files show their first items instantly; sorting, filtering and selecting stay fluid
- **Finder tags:** show and set coloured tags, tags in the sidebar, `tag:red` in the filter
- **Get Info (⌘I):** a window with size, locations, dates, tags, Open With and permissions
- **Search across folders:** in subfolders or with Spotlight on the whole Mac, including file contents
- **WebDAV and SMB:** connect Nextcloud, ownCloud and Windows/NAS shares directly; network volumes with an Eject button
- **Discover plugins:** install community plugins right from Settings (checksum-verified), double-click `.mantaplugin` files; third-party plugins run in a macOS sandbox
- **Live refresh in every tab** and smaller updates
- **Crash reports without tracking:** after a crash Manta offers to report a scrubbed report on GitHub – nothing is sent automatically
