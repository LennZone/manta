## Manta 0.4.1 – safer resumed transfers

- **Byte-exact resume:** when Manta quits during a copy, it now waits for running transfers to stop before saving their state, so a resumed copy can never append data twice
- **Checked before continuing:** the end of a partial file is compared with the source before a transfer resumes; if it doesn't match, the file is copied again from the start
- **Size check at the end:** a copy whose final size is wrong is redone and never reported as done
- **Same file copied twice at once:** two simultaneous copies of the same file into the same folder no longer share a partial file
