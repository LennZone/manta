## Manta 0.4.1 – sicherer fortgesetzte Übertragungen

- **Byte-genaues Fortsetzen:** Wird Manta während einer Kopie beendet, wartet es jetzt, bis laufende Übertragungen gestoppt sind, bevor ihr Stand gespeichert wird – eine fortgesetzte Kopie kann so nie Daten doppelt anhängen
- **Vor dem Weitermachen geprüft:** Das Ende einer Teildatei wird vor dem Fortsetzen mit der Quelle verglichen; passt es nicht, wird die Datei neu von vorn kopiert
- **Größenprüfung am Ende:** Eine Kopie mit falscher Endgröße wird wiederholt und nie als fertig gemeldet
- **Dieselbe Datei zweimal gleichzeitig kopiert:** Zwei gleichzeitige Kopien derselben Datei in denselben Ordner teilen sich keine Teildatei mehr
