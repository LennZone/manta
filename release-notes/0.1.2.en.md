## Get there faster

- **New: type to jump.** Type the first letters of a name in the file list and the selection jumps right there, just like Finder. After a short pause a new word starts; the space bar still opens Quick Look.
- **Improved: FTPS.** Connections to servers that require a resumed TLS session (e.g. All-Inkl) now work. If your network blocks encrypted data connections, Manta switches to an unencrypted data connection automatically and tells you so – the login always stays encrypted. Choose Automatic, Required or Off in the Connect dialog.
